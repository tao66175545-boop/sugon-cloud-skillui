# 政企汇报文风与字体（v0.4.5）

- 标题用**结论句**，避免「情况说明」「工作汇报」空标题。
- 一页一个重点；红面积目测 < 内容区 8%（封面/章节除外）。
- 正文 `#333333`，辅助 `#666666`，禁止浅灰字压浅灰卡（禁 `#999` on `#F5F5F5`）。
- 字体名：`Source Han Sans SC` / `Noto Sans CJK SC`；**不嵌入**；导出禁微软雅黑。
- 禁用 Wingdings / Symbol 做项目符号。
- 边距：L/R 0.6" · 顶 0.45" · 底 0.4"；列 gutter 0.2"。
- 同稿章节语法二选一：`section-number` 或 `section-part`。
