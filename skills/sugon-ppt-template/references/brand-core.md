# 品牌摘要（PPT）

| 角色 | HEX | 用途 |
|------|-----|------|
| 识别红 brand.red | `#AF1F24` | PPT 强调条、标题强调、与 logo 一致的主色 |
| Logo 灰 | `#727272` | 仅 logo 内，不作正文灰 |
| UI 红 | `#C8161D` | **网页按钮**；PPT/印刷不要当主色 |
| 正文 | `#171717` | 近黑 |
| 次要文字 | `#525252` | 说明 |
| 浅底 | `#F4F4F5` / `#FAFAFA` | 卡片/隔页底 |
| 白 / 边框 | `#FFFFFF` / `#E5E5E5` | 背景与分割 |

Logo：横式官方 SVG/PNG，勿改成 UI 红。细则见 `sugon-brand-core` / `sugon-logo-usage`。
