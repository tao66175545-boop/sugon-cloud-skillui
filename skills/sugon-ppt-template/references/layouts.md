# 版式说明（16:9 · LAYOUT_WIDE 13.333×7.5 in）

边距建议 ≥ 0.5 in。页脚可选「内部资料 · 注意保密」+ 页码。

| 版式 id | 用途 | 要点 |
|---------|------|------|
| `cover` | 封面 | 左上或右上 logo；主标题（结论式）；副标题；单位全称；日期 YYYY 年 M 月；底边识别红条 |
| `agenda` | 目录 | 「目录」标题；编号条目（原生 bullet，勿用 Wingdings）；可选右侧短说明 |
| `section` | 章节隔页 | 大号章节号 + 章节名；识别红强调条；少正文 |
| `content` | 单栏正文 | 结论句标题；要点列表；可附注 |
| `two-col` | 双栏 | 左/右等宽栏，各有小标题与要点 |
| `chart` | 图表占位 | 标题 + 图表区域说明（「此处插入数据图」）；本通用稿用表格示意，正式稿换原生图表 |
| `closing` | 结束页 | 「谢谢」或「请指正」；联系方式可选；logo；单位名 |

样例 deck 至少包含：`cover` → `agenda` → `content` ×2 → `closing`。
