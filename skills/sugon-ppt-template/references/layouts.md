# 版式说明（16:9 · LAYOUT_WIDE 13.333×7.5 in）

边距建议 ≥ **0.65 in**。页脚可选「内部资料 · 注意保密」+ 页码。  
品牌强调：标题左侧**短竖标** + 标题下**短红线**（不用全高侧栏 / 通栏粗底条）。

| 版式 id | 用途 | 要点 |
|---------|------|------|
| `cover` | 封面 | 左上 logo；大号结论式主标题；短红线；副标题；单位 + 日期（底区，不挤） |
| `agenda` | 目录 | 「目录」+ 短红线；红色两位编号 + 等距条目；浅分隔线 |
| `section` | 章节隔页 | 浅底；大号章节号（红）+ 章节名；短红线；少正文 |
| `content` | 单栏正文 | 结论句标题；浅底圆角卡片内编号要点；可附注 |
| `two-col` | 双栏 | 等宽浅底卡片；栏内短红线 + 小标题 + bullet |
| `stats` | 数据要点 | 三列（或 N 列）浅底卡片；大号红数字 + 说明 |
| `chart` | 图表占位 | 标题 + 图表区域说明；正式稿换原生图表（样例可用 stats 代替） |
| `closing` | 结束页 | 居中 logo +「谢谢 / 请指正」+ 短红线 + 单位 + 联系占位 |

样例 deck（v0.4.2）：`cover` → `agenda` → `section` → `content` → `two-col` → `stats` → `closing`。
