# GATES · 出门禁（任一项否 = 不过）

## V 视觉否决

- [ ] Page 非 `#FFFFFF` 或大面积深灰/黑底
- [ ] Brand 面积 >8% 或每页强调装置 >2
- [ ] 红线/红块带黑描边
- [ ] 大黑圆点 / 粗黑箭头 / 侧栏色带 / 发丝框墙
- [ ] MistSand 或脏粉奶油洗开启
- [ ] 造型为异形乱多边形 / 锯齿 / 斜叶乱盘等「看着很乱」
- [ ] 缩略读成等分灰卡墙 / bento / 页间可互换同壳

## L 排版否决

- [ ] inset 左右 ≠ 56 或 title/cards/footer 左缘不齐
- [ ] Logo 非 2.5:1 或右缘不齐内容
- [ ] 栏内/卡内文字顶齐漂（未垂直居中）
- [ ] 间距未落 8pt 栅格（忽挤忽空）
- [ ] 字阶混档（PageTitle<36 / Body 越档等）

## C 内容否决

- [ ] 冻结页被改版式（仅允许页脚共 N 更新）
- [ ] 文案题面偏离定稿 COPY
- [ ] 页脚非 `内部资料｜第n页/共N页` 或右侧重复页码
- [ ] 假百分比 / 无来源 KPI

## 通过标准

全部勾选框保持未触发（无否决）且十页（或本段）缩略一眼可辨、干净圆角，方可交付。
