# 字体与授权（由 tokens/sugon.brand.json 生成）

- **默认正文/标题**：Source Han Sans SC / Noto Sans CJK SC
- **可选标题**：Alibaba PuHuiTi / 阿里巴巴普惠体
- **Office 编辑回退（禁止出图）**：Microsoft YaHei / 微软雅黑

## 规则

- 仓库不附带字体文件，只引用名称与官方下载链接。
- 导出的图片 / PDF / 网页禁止出现微软雅黑（商用授权风险）；Office 编辑时可用作回退。
- PPT 默认不嵌入字体（国产 WPS / 信创可能崩溃）。
- 思源黑体在 Linux 上常显示为 Noto Sans CJK SC，字体栈两个名字都要写。
