# 品牌颜色（由 tokens/sugon.brand.json 生成）

| Token | HEX | CSS 变量 | 用途 |
|-------|-----|----------|------|
| brand.red | `#AF1F24` | `--color-brand-red` | logo / VI / PPT / 印刷 / 新媒体 / 名片。与 UI primary #C8161D 不同，同一画面只选一种红作主色。 |
| brand.gray | `#727272` | `--color-brand-gray` | 仅用于 logo 与标准字，不作正文灰。 |
| ui.primary（对照） | `#C8161D` | `--color-primary` | 网页按钮 / 链接；**不要**用于 logo |

同一画面只选一种红作为主色。网页 UI 用 --color-primary；logo/VI/PPT/印刷用 brand.red。logo 永远用原稿，不跟随 UI 主题重新着色。
