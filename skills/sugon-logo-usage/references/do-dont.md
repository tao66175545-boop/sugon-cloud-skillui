# Logo 做 / 不做

数值草案来自 `tokens/sugon.brand.json`（标「待确认」的项需品牌方拍板）。

## 做

- 使用 `assets/logo/sugon-cloud-logo.svg` 原稿（品牌红 `#AF1F24` + 灰 `#727272`）
- 浅色背景用原色稿；深色背景等反白稿到位后再用
- 保持宽高比（约 2.506:1），等比缩放
- 四周留出安全空间（草案：约 0.3 × logo 高度）
- 屏幕宽度 ≥ 120px；印刷宽度 ≥ 25mm（草案）

## 不做

- 拉伸、压扁、旋转
- **改色**（包括改成 UI 红 `#C8161D`）
- 加描边、阴影、渐变、发光
- 拆开「Sugon」与「曙光云」另行排列
- 重新绘制或换字
- 放在低对比度或杂乱背景上
- 深底仍用原色稿（红在深底上对比不足）

可用 `scripts/check-logo.mjs` 扫描 SVG/HTML/CSS，拦截把 `#AF1F24` 换成非白名单色的改动。
